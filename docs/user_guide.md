# 用户指南

## 启动

首次运行双击 `setup.bat` 安装依赖，之后双击 `start.bat`。

## 二进制加解密

输入恰好 8 位二进制分组和 10 位二进制密钥，选择加密或解密并点击“执行”。页面会显示 K1、K2、IP、两轮 F 函数和最终置换过程。

## ASCII 字符串

输入 ASCII 文本和密钥后加密。密文使用十六进制显示，避免控制字符和乱码；解密时读取可编辑的十六进制区域。中文不属于 ASCII，程序会给出提示。

## 暴力破解

每行输入一组：

```text
8位明文 8位密文
```

点击“枚举全部 1024 个密钥”。程序保留所有候选，而不是找到第一个就停止。增加明密文对只能缩小或保持候选集合。

## 碰撞分析

点击“执行完整分析”，程序遍历全部 256 个明文和 1024 个密钥，显示碰撞范围、完整映射数量与等效密钥情况，并可导出 CSV/JSON。

## 注意

- 前导零不能省略。
- 输入框不接受多余空格。
- 错误密钥可能使 ASCII 解密结果无效。
- S-DES 密钥空间极小，只能用于课程实验。
