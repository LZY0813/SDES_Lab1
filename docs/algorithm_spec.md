# S-DES 算法规范

## 参数

- 分组：8 bit
- 密钥：10 bit
- 位序：输入左端为最高位，置换位置从 1 开始
- `P10=(3,5,2,7,4,10,1,9,8,6)`
- `P8=(6,3,7,4,8,5,10,9)`
- `IP=(2,6,3,1,4,8,5,7)`
- `IP⁻¹=(4,1,3,5,7,2,8,6)`
- `EP=(4,1,2,3,2,3,4,1)`
- `SP/P4=(2,4,3,1)`

SBox1：

```text
1 0 3 2
3 2 1 0
0 2 1 3
3 1 0 2
```

课程修改版 SBox2：

```text
0 1 2 3
2 3 1 0
3 0 1 2
2 1 0 3
```

S-Box 输入 `b1b2b3b4`，行号为 `b1b4`，列号为 `b2b3`。

## 密钥扩展

严格按照：

```text
Ki = P8(Shift^i(P10(K))), i=1,2
```

执行：

1. P10(K) 分成左右两个 5-bit 半区；
2. 从 P10 结果分别循环左移 1 位，生成 K1；
3. 再次从原 P10 结果分别循环左移 2 位，生成 K2；
4. Shift² 不累计在 Shift¹ 的结果上。

## 加解密

```text
加密：IP → fk(K1) → SW → fk(K2) → IP⁻¹
解密：IP → fk(K2) → SW → fk(K1) → IP⁻¹
```

`fk(L||R,K)=(L XOR F(R,K))||R`。

## 独立逐位向量

输入 `P=11010111`、`K=1010000010`：

| 步骤 | 值 |
|---|---|
| P10(K) | 10000 01100 |
| Shift¹ | 00001 11000 |
| K1 | 10100100 |
| Shift²（从 P10 开始） | 00010 10001 |
| K2 | 10010010 |
| IP(P) | 1101 1101 |
| 第1轮 EP / XOR | 11101011 / 01001111 |
| 第1轮 SBox / P4 / fk | 11 11 / 1111 / 00101101 |
| SW | 11010010 |
| 第2轮 EP / XOR | 00010100 / 10000110 |
| 第2轮 SBox / P4 / fk | 00 11 / 0110 / 10110010 |
| IP⁻¹，密文 | 11101000 |

反向使用 K2、K1，可将 `11101000` 解密为 `11010111`。
